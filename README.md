# Homebrew tap for Ferrocast

```bash
brew install drumst0ck/ferrocast/ferrocast
ln -sfn "$(brew --prefix)/opt/ferrocast/Ferrocast.app" /Applications/Ferrocast.app
open /Applications/Ferrocast.app
```

Prefer a download? Grab the DMG from [the latest release](https://github.com/drumst0ck/ferrocast/releases/latest).

This tap only holds the formula. The app lives in [drumst0ck/ferrocast](https://github.com/drumst0ck/ferrocast).
The formula is bumped automatically (hourly, and on demand) to the latest stable release.
